# 손끝 도장

카메라 앞에서 손 모양을 만들면 술법이 펼쳐지는 웹캠 놀이터입니다.

| 손 모양 | 술법 | 효과 |
| --- | --- | --- |
| 손바닥을 활짝 펴기 | 회오리 구슬 | 손바닥 위에서 빛나는 구슬이 돕니다 |
| 두 손 검지를 열십자로 겹치기 | 그림자 나누기 | 내 모습이 양옆에 더 나타나 함께 움직입니다 |
| 주먹을 쥐고 잠깐 버티기 | 바람결 숨기 | 연기와 나뭇잎을 남기고 화면에서 사라집니다 |

손 모양이 잘 잡히지 않으면 화면 왼쪽 위 안내에서 술법 이름을 누르거나 키보드 `2`, `3`을 눌러도 됩니다.
사라지는 효과가 어색하면 `배경 찍기`를 누르고 3초 동안 화면 밖으로 비켜 주세요.

## 동작 방식

- 빌드 과정 없이 `index.html` 하나로 동작합니다.
- 손 인식과 인물 분리는 MediaPipe Tasks Vision을 브라우저에서 직접 실행합니다.
- 영상은 기기 안에서만 처리되고 서버로 전송되지 않습니다.

## 로컬에서 실행

카메라는 `https` 또는 `localhost`에서만 켜집니다.

```sh
npx serve .
```
